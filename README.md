### Project Description
Worst Route Finder is a satirical navigation app designed for a useless hackathon. Instead of guiding users through the shortest route, it deliberately finds the most inefficient, looping, and time-consuming path to a given destination — proving that not all maps are made to help.

### The Problem (that doesn't exist)
Finding the shortest route has become too mainstream. What about people who have too much time, want to waste fuel, or just enjoy getting lost? There's a shocking lack of apps that help users take the longest, most unnecessary path to their destination — and we’re here to fix that.

### The Solution (that nobody asked for)
We proudly present the Worst Route Finder — an app that uses the power of maps and utter disregard for efficiency to generate the most convoluted, fuel-guzzling, time-wasting route imaginable. By dynamically choosing detours, loops, and roads that make no sense, we make sure you'll reach your destination… eventually.

### Implementation
Implementation
For Software:

The user selects a source and destination (e.g., Technopark to Attingal).

The app sends these coordinates to the Gemini API, which generates a wildly inefficient route, roughly 5x longer than the shortest path.

This route may include scenic detours, U-turns, loopbacks, and even temporary diversions in entirely the wrong direction — all on purpose.

The route is displayed using Google Maps API, complete with a polyline and turn-by-turn instructions.

The app is built using Flutter, making it cross-platform for Android and iOS, with Firebase managing backend operations like storing trip history or user profiles.

If needed, users can share or save their ridiculous journey for future un-optimized travel.
